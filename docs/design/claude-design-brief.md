# 디자인 브리프 — 한반도 생명 연대기

> Claude Design 입력용. 기능·데이터는 이미 동작하는 MVP가 있고, **화면 디자인만 새로** 잡는 것이 목적이다.

> `current-4-paleozoic.png`, `current-5-iceage-overlay.png` (함께 첨부).

## 1. 서비스 한 줄

시간 슬라이더로 한반도의 과거를 거슬러 올라가며, **그 시대 이 땅에 살았던 생물**과 **그 생물이 오늘 어떤 동물로 이어지는지**를 보여주는 인터랙티브 웹.

핵심 정체성: **지도(공간) · 타임라인(시간) · 계통수(진화)** 세 뷰가 서로 연동된다. 하나를 고르면 나머지 둘이 같이 반응한다.

## 2. 사용자와 톤

- 고생물·진화에 관심 있는 일반인과 학생(중·고등), 공룡 화석지 방문 전후로 찾아보는 가족, 교사·학부모
- 톤: **자연사 박물관 전시 + 탐험 지도**. 신뢰감 있고 차분하되 아이들도 흥미를 느끼는 수준. 유치한 만화풍은 피한다.
- 언어: 한국어 전용. 학명은 이탤릭 보조 표기.
- 대표 "와!" 순간 (디자인으로 강조할 것)
  1. 강원도 산골이 4.8억 년 전엔 **적도 근처 따뜻한 바다**였다
  2. 공룡이 걷던 경상도 **호숫가** 바로 옆 바다엔 **수장룡**이 헤엄쳤다
  3. 2만 년 전엔 **서해가 걸어서 건너는 평원**이었다
  4. 고성 공룡 발자국에서 출발해 **까치**까지 이어지는 계통 경로

## 3. 현재 디자인의 문제 (고쳐야 할 것)

- 대시보드처럼 패널 4개(지도·카드·필터·계통수)가 같은 무게로 나열돼 **이야기 흐름이 없다**
- 시대가 바뀌어도 화면 분위기가 그대로라 **시간 여행 느낌이 약하다**
- 계통수가 화면 하단에 길게 붙어 있어 스크롤해야 보이고, 노드 라벨이 겹친다
- 생물 카드가 텍스트 위주라 단조롭다 (이미지 없음)
- 한 지점에 화석 마커가 6~8개 겹친다 (지금은 클릭하면 목록 팝업으로 처리)
- 모바일 레이아웃이 없다

## 4. 화면 구성 요소 (모두 유지해야 함)

### 4.1 타임라인
- 시대 3개로 스냅: **고생대 바다**(480 Ma, 약 4.8억 년 전) · **백악기 — 공룡 시대**(100 Ma, 약 1억 년 전) · **신생대 빙하기**(약 2만 년 전)
- 왼쪽이 과거, 오른쪽이 현재. 시대명, "약 N억 년 전", 지질시대명(캄브리아기~오르도비스기 / 백악기 전기~후기 / 최종빙기 최성기) 표시
- 시대별 한 줄 설명과 강조 문구(위의 "와!" 문장)
- 고생대·빙하기는 "미리보기" 상태 표시 (콘텐츠가 적음). 백악기가 완성 시대
- 앞으로 시대가 늘어날 예정 (쥐라기, 페름기 대멸종, 마이오세 포항) → 5~7개까지 늘어나도 버티는 구조

### 4.2 지도 뷰 (화면의 주인공)
- 모드 3개 토글
  - **과거 지도 (판 복원)**: 판 구조 모델로 복원한 당시 대륙·바다 배치 + 오늘의 한반도 윤곽(노란 윤곽)을 당시 위치로 옮겨 겹침
  - **현재 지도**: 실제 발견지 좌표
  - **현재 지도 + 당시 환경**: 오늘 지도 위에 당시 환경(호수 분지, 얕은 바다, 드러난 서해 평원)을 손으로 그린 개략 영역으로 표시
- 지도 레이어: 바다 배경, 육지, 한반도 윤곽, 환경 영역, **화석 마커**, PBDB 산출 기록 점(선택), 논쟁 구간 **빗금**
- 마커: 생물 그룹별 색. 동아시아 참고 화석(일본·중국)은 **시각적으로 구분**(현재는 반투명)
- 마커 호버 = 이름 툴팁, 클릭 = 생물 카드. 겹친 마커는 목록에서 선택
- 지도 하단에 상황별 안내 한 줄 (예: "노란 윤곽 = 오늘의 한반도를 100Ma 시점으로 되돌린 위치. 판 구조 모델 기반 추정이에요.")
- 출처 표기(attribution) 필수: GPlates · Merdith et al. 2021 / Natural Earth / PBDB / 국가유산청
- 빙하기 전용 **해수면 슬라이더**(0 ~ -130m)가 들어갈 자리 필요 (현재는 비활성, 다음 단계에서 활성화)

### 4.3 생물 카드
표시 항목:
- 한글명, 학명(있을 때, 이탤릭)
- 생물 그룹 칩(색), 특이사항 배지
- 분류 위치 (예: 지배파충류 › 공룡 › 용반류 › 수각류)
- 생존 시기 (예: 113–100 Ma, 대략)
- 화석 종류: 발자국 / 알 / 골격 / 이빨·미화석
- 발견지 (지명 + 좌표, 대략)
- PBDB 기록 수 (예: "반경 15km 내 같은 시대 산출 기록 58건")
- 설명 2~4문장
- 출처
- 주 행동 버튼 **「오늘로 이어보기 →」**
- 이어보기 결과 박스: "수각류에서 갈라져 오늘까지 이어진 친척: 까치, 두루미, 청둥오리" + 주의 문구 **"※ 직계 조상이 아니라, 공통 조상에서 갈라진 친척 관계예요."** (항상 보여야 함)
- 빈 상태: "지도에서 화석 마커를 누르거나, 계통수에서 가지를 눌러 보세요." + 추천 시작점
- 계통수 노드만 고른 경우 카드: 이름, 학명, 현생종/멸종/논쟁 중 배지, 등장 시기, 메모

배지 종류 (의미가 정확히 전달돼야 함):
| 배지 | 의미 | 강조도 |
|---|---|---|
| 공룡 아님 | 익룡·수장룡·모사사우루스 | 높음 (오해가 가장 흔함) |
| 종 특정 불가 | 발자국·알이라 그룹 단위로 연결 | 중간 |
| 동아시아 참고 | 한반도 밖 같은 시대 화석 | 중간 |
| 흔적 화석 | 몸이 아닌 활동 흔적 | 낮음 |
| 논쟁 중 | 분류 위치 학계 이견 | 중간 (점선 계열 시각 언어) |

### 4.4 계통수 뷰
- 가로축 = 시간 (6억 년 전 → 오늘). 기준선: 캄브리아기 시작 / 페름기 말 대멸종 / 백악기 말 대멸종 / 오늘
- 현재 46개 노드, 현생종 잎 14개 (향후 수백 개까지)
- 멸종 가지는 멸종 시점에서 끝남 + † 표시, 논쟁 중 분기는 **점선**
- 선택된 시대의 구간을 띠로 표시, 그 시대 한반도 화석이 연결된 가지에 점 표시
- 「오늘로 이어보기」 경로를 굵은 강조색으로 하이라이트
- 노드 클릭 → 카드 갱신 + 해당 화석이 있으면 지도 이동
- 범례 + "현재 가장 지지받는 가설이며 분기 시점은 대략값" 안내

### 4.5 오늘의 생물에서 거슬러 오르기 (역방향 탐색)
- 현생 한국 생물 14종 칩: 꽃게, 개맛, 붕어, 고라니, 상괭이, 반달가슴곰, 남생이, 아무르장지뱀, 까치, 두루미, 청둥오리 …
- 누르면 → 가장 가까운 한반도 화석으로 타임라인·지도·카드가 자동 이동 + 안내 문장 (예: "고라니와 「단양 구낭굴 사슴류 화석」는 사슴과 계통을 공유하는 친척이에요.")
- 향후 검색창으로 바뀔 수 있음

### 4.6 필터·옵션
- 생물 그룹 체크박스 (시대에 존재하는 그룹만): 수각류, 용각류, 조각류, 각룡류, 공룡(미분류), 조류, 익룡, 해양 파충류, 어류, 무척추동물, 포유류
- 동아시아 참고 화석 표시 on/off
- PBDB 산출 기록 점 on/off (건수 표시)

### 4.7 알아두기 (교육 카드)
- 수장룡·어룡·모사사우루스·익룡은 공룡이 아니에요.
- 새는 수각류 공룡에서 갈라져 나온 계통이에요.
- 고래는 육지 포유류가 다시 바다로 돌아간 경우예요.
- 고지리 지도는 판 구조 모델 기반 추정이에요.

## 5. 반드시 지킬 정확성 원칙 (디자인 제약)

1. **불확실성은 숨기지 않는다** — 모델 추정·논쟁 정보는 점선·빗금·배지·툴팁으로 눈에 보이게
2. 화석 생물을 현생종의 **직계 조상처럼 그리지 않는다** — 화살표 "A → B 진화" 같은 표현 금지, "친척/갈라짐" 시각 언어
3. **"공룡 아님" 그룹 명확히 구분**
4. **모든 카드·레이어에 출처** — 작게라도 항상 보이게
5. 좌표·연대는 "대략" 표기 유지

## 7. 요청 사항

1. **데스크톱(1440px) 메인 화면** — 백악기 선택 + 「고성 수각류 발자국」 선택 + 오늘로 이어보기 실행 상태
2. **시대별 분위기 차이** 제안 (고생대 바다 / 백악기 / 빙하기) — 색·질감·헤더 등으로 시간 여행 느낌
3. **계통수 배치 재설계** — 지도와 동시에 보이거나, 이어보기 시 자연스럽게 드러나는 방식
4. **생물 카드 재설계** — 이미지/일러스트 자리 포함 (실루엣 아이콘 등, 실제 사진은 아직 없음)
5. **모바일(390px)** — 지도 우선, 카드는 바텀시트, 계통수는 별도 탭 등
6. **첫 진입 경험** — 처음 온 사람이 "고성 발자국 → 까치" 흐름을 자연스럽게 따라가도록 하는 장치 (온보딩, 추천 경로 등)
7. 빈 상태 / 로딩 / 데이터 오류 상태

## 8. 구현 제약 (디자인 결과를 코드로 옮길 때)

- React + TypeScript (Vite), 상태는 Zustand
- 지도: **MapLibre GL** — 배경 타일 없이 GeoJSON 벡터 레이어만 (바다 = 배경색, 육지 = 폴리곤 채움). 마커는 circle 레이어 또는 HTML 마커. 이미지 패턴(빗금) 가능
- 계통수: SVG (D3 레이아웃 계산, React 렌더)
- 정적 사이트 (서버 없음), 외부 폰트·이미지 사용 가능
- 웹폰트 제안 환영 (현재 Pretendard → 시스템 폰트 폴백)

## 9. 실제 데이터 예시

**생물 카드 예 — 고성 수각류 발자국**
- 그룹: 수각류 / 배지: 종 특정 불가
- 분류: 지배파충류 › 공룡 › 용반류 › 수각류
- 113–100 Ma (대략) · 발자국 · 경남 고성 하이면 덕명리 일대 (34.95, 128.29)
- PBDB 반경 15km 기록 58건
- 설명: 고성 해안 일대의 진동층에는 수많은 공룡 발자국이 층층이 남아 있습니다. 세 개의 뾰족한 발가락 자국은 두 발로 걷던 육식성 수각류의 것입니다. 발자국만으로는 종을 특정할 수 없어 '수각류' 그룹 단위로 연결했습니다.
- 출처: 국가유산청 천연기념물 「고성 덕명리 공룡과 새발자국 화석산지」 · PBDB
- 이어보기 → 수각류 › 조류 › 현생 조류 › 까치 / 두루미 / 청둥오리

**백악기 화석 목록 (17)**
국내: 고성 수각류·용각류·조각류 발자국, 진주 랩터 발자국(*Dromaeosauriformipes rarus*), 화순 서유리 수각류 발자국, 의성 제오리 공룡 발자국, 해남 우항리 익룡 발자국(*Haenamichnus*, 공룡 아님), 해남 우항리 물새 발자국(*Uhangrichnus*), 화성 시화호 공룡알, 보성 비봉리 공룡알, 코리아노사우루스, 코리아케라톱스, 부경고사우루스, 진주층 민물고기 화석
동아시아 참고: 후타바사우루스(후쿠시마, 수장룡), 포스포로사우루스(홋카이도, 모사사우루스류), 시노사우롭테릭스(랴오닝, 깃털 공룡)

**고생대 (3)**: 영월 삼엽충, 태백 완족류, 단양 코노돈트(논쟁 중)
**빙하기 (2)**: 단양 구낭굴 곰 화석, 단양 구낭굴 사슴류 화석
