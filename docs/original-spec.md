# 한반도 생명 연대기 (가제) — 개발 명세서

> 시간 슬라이더로 한반도의 과거를 거슬러 올라가며, 그 시대 이 땅(과 주변 바다)에 살았던 생물과
> 그 생물이 오늘날 어떤 동물로 이어지는지 보여주는 인터랙티브 웹 서비스.

---

## 1. 개요

### 1.1 핵심 컨셉
세 개의 뷰가 서로 연동되는 것이 서비스의 정체성이다.

| 뷰 | 축 | 역할 |
|---|---|---|
| 지도 뷰 | 공간 | 시대별 고지리 지도 + 화석 발견 지점 |
| 타임라인 뷰 | 시간 | 시대 선택 슬라이더, 지질시대 구분 |
| 계통수 뷰 | 진화 | 생물 간 관계, 과거 생물 → 현생 생물 경로 |

하나의 뷰에서 무언가를 선택하면 나머지 두 뷰가 함께 반응한다.

### 1.2 대상 사용자
- 고생물·진화에 관심 있는 일반인, 학생
- 공룡 화석지 방문 전후로 정보를 찾는 사람
- 교육용 자료가 필요한 교사·학부모

### 1.3 설계 원칙
1. **정적 데이터 우선**: 외부 API를 실시간 호출하지 않는다. 전처리 스크립트로 JSON을 미리 만들고 웹은 읽기만 한다.
2. **불확실성은 숨기지 않는다**: 논쟁 중이거나 모델 기반 추정인 정보는 화면에 명시한다 (점선, 배지, 툴팁).
3. **출처 표기**: 모든 생물 카드와 지도 레이어에 데이터 출처를 남긴다.
4. **작게 시작해 관통**: 한 시대를 지도 → 카드 → 계통수까지 끝까지 완성한 뒤 확장한다.

## 2. 콘텐츠 범위

### 2.1 시대 구성

MVP는 3개 시대, 이후 확장.

#### ① 고생대 바다 — 캄브리아~오르도비스기 (약 5억~4.5억 년 전)
- 현재의 강원 남부·충북 일대(태백, 영월, 단양)는 당시 저위도의 얕은 바다
- 조선누층군 석회암 지층: 삼엽충, 완족류, 원시 어류 흔적
- 연출 포인트: "강원도 산골이 원래 따뜻한 바다였다"

#### ② 백악기 — 공룡 시대 (약 1억 년 전) ★ 핵심 시대
- 경상도 일대의 거대한 호수 분지(경상분지)
- 주요 화석지
  - 고성: 공룡 발자국 (조각류·용각류·수각류)
  - 해남 우항리: 익룡·물새 발자국
  - 화성 시화호, 보성 비봉리: 공룡알
  - 진주층 등: 민물고기 화석
- 한국에서 명명된 공룡: 부경고사우루스(하동), 코리아노사우루스(보성), 코리아케라톱스(화성)
- **동아시아 참고 레이어**: 같은 시대 일본의 해양 파충류(예: 후쿠시마 수장룡 후타바사우루스) 등
- 연출 포인트: 공룡이 걷던 호숫가 바로 옆 바다엔 수장룡이 헤엄쳤다는 대비

#### ③ 신생대 빙하기 — 최종빙기 최성기 (약 2만 년 전)
- 해수면이 현재보다 약 120m 낮음 → 서해 전체가 육지
- 석회암 동굴(단양 구낭굴 등)의 플라이스토세 포유류 화석
- 대한해협 완전 폐쇄 여부는 학계 논쟁 → **불확실 표시 필수**
- 연출 포인트: 해수면 슬라이더로 서해가 드러나는 장면

#### 확장 후보
- 신생대 마이오세 포항 일대: 해양 어류, 상어 이빨, 고래 등 해양 포유류
- 페름기 말 대멸종
- 쥐라기

### 2.2 생물 그룹

| 그룹 | 한국 출토 자료 | 처리 방식 |
|---|---|---|
| 무척추동물 (삼엽충 등) | 풍부 (고생대) | 한국 출토 마커 |
| 어류 | 있음 (고생대, 백악기 호수, 신생대 포항) | 한국 출토 마커 + 계통수 뿌리 |
| 공룡 | 풍부 (주로 발자국·알, 일부 골격) | 한국 출토 마커 |
| 익룡 | 있음 (발자국) | 한국 출토 마커, "공룡 아님" 표시 |
| 해양 파충류 (수장룡·어룡·모사사우루스) | 거의 없음 | 동아시아 참고 레이어, "공룡 아님" 표시 |
| 포유류 | 있음 (빙하기 동굴, 신생대 해양 포유류) | 한국 출토 마커 |
| 현생 생물 | 국가생물종목록 | 계통수 종착점, 역방향 탐색 시작점 |

### 2.3 마커 구분
- `korea`: 한반도에서 실제 출토된 화석
- `east_asia_reference`: 주변 지역(일본, 중국 동부) 참고 화석 — 시각적으로 구분 (색상/투명도)

## 3. 기능 명세

### 3.1 타임라인 슬라이더
- 시대 단위 스냅 (MVP: 3개 지점)
- 시대명, 연대(Ma), 지질시대 구분 표시
- 시대 변경 시 지도 배경·마커·하이라이트 생물 갱신

### 3.2 지도 뷰
- 배경: 선택된 시대의 고지리 래스터 (대륙·바다 배치)
- 한반도 영역 하이라이트 (현재 해안선 윤곽을 과거 위치로 복원해 오버레이)
- "현재 지도와 겹쳐보기" 토글 (반투명 오버레이)
- 화석 마커: 과거 시대 보기에서는 복원 좌표, 현재 지도 보기에서는 실제 발견지 좌표
- 마커 필터: 생물 그룹별, 출토 구분(korea / east_asia_reference)

### 3.3 해수면 슬라이더 (빙하기 전용)
- 범위: 0m ~ -130m
- GEBCO 수심 그리드에서 슬라이더 값보다 얕은 셀을 육지로 렌더링
- 대한해협 등 논쟁 구간은 해칭/툴팁으로 불확실성 표시

### 3.4 생물 카드
표시 항목:
- 한글명, 학명
- 생물 그룹, 분류 위치 (상위 분류군 2~3단계)
- 생존 시기 (Ma 범위)
- 화석 종류 (골격 / 발자국 / 알 / 이빨 등)
- 발견지 (지명 + 좌표)
- 간단 설명 (2~4문장)
- 특이사항 배지: `공룡 아님`, `종 특정 불가 (발자국)`, `동아시아 참고` 등
- 데이터 출처
- 버튼: **오늘로 이어보기**

### 3.5 계통수 뷰
- 가로축 = 시간 (과거 → 현재), D3 트리/덴드로그램
- 루트: 어류(척추동물) 수준에서 시작
- 주요 가지: 어류 → 사지동물 → (파충류: 공룡 → 조류 / 익룡 / 해양 파충류) / (단궁류 → 포유류 → 고래)
- 멸종 가지는 생존 시기에서 끝나도록 표시
- 논쟁 중인 분기는 점선
- 노드 클릭 시 생물 카드 표시, 해당 생물이 지도에 있으면 지도 이동

### 3.6 오늘로 이어보기 (정방향)
- 과거 생물 → 현생 생물까지의 경로 하이라이트
- 발자국처럼 종 특정이 안 되는 경우 그룹 단위(예: 수각류)에서 출발
- 경로 끝에 한국 현생종 예시 표시 (예: 수각류 → 조류 → 까치, 두루미)
- 직계 조상처럼 오해하지 않도록 "공통 조상에서 갈라진 친척 관계"라는 안내 문구

### 3.7 역방향 탐색
- 현생 한국 생물 검색 (예: 고라니, 까치, 붕어)
- 조상 계통을 거슬러 올라가 가장 가까운 한반도 화석 생물 표시
- 해당 시대로 타임라인 자동 이동

### 3.8 교육용 설명 카드 (상시 노출 or 툴팁)
- "수장룡·어룡·모사사우루스·익룡은 공룡이 아니에요"
- "새는 수각류 공룡에서 갈라져 나온 계통이에요"
- "고래는 육지 포유류가 다시 바다로 돌아간 경우예요"
- "고지리 지도는 판 구조 모델 기반 추정이에요"

## 4. 데이터 소스

| 용도 | 소스 | 비고 |
|---|---|---|
| 화석 기록 + 당시 좌표 | Paleobiology Database (PBDB) API | `cc=KR` 등 국가 필터, 고좌표(paleoloc) 포함 가능 |
| 국내 화석지 보강 | 국가유산청 천연기념물 데이터, 국내 논문 | PBDB에 빠진 국내 화석지 수작업 보강 |
| 동아시아 참고 화석 | PBDB (`cc=JP`, `cc=CN` 등) | 해양 파충류 등 |
| 고지리 배경 지도 | PALEOMAP (Scotese) | **사용 전 라이선스 조건 확인** |
| 좌표 복원 | GPlates Web Service | 현재 좌표 → 시대별 과거 좌표 |
| 해수면/수심 | GEBCO 그리드 | 한반도 주변만 잘라서 사용 |
| 계통수 구조 | Open Tree of Life API | 학명 매칭(TNRS) + 서브트리 추출 |
| 분기 시점 | TimeTree | API 제공 방식 확인 필요, 안 되면 주요 분기만 수작업 |
| 한국 현생종 | 국가생물종목록 (국립생물자원관), 공공데이터포털 | 학명 기준으로 Open Tree ID와 매칭 |
| 현생종 관찰 (선택) | GBIF (`country=KR`), iNaturalist | 사진·분포 보강 |

> 각 소스의 엔드포인트·파라미터는 구현 시점에 공식 문서로 재확인할 것.

## 5. 데이터 파이프라인

전처리는 Python 스크립트로 수행하고 결과를 `data/processed/`에 JSON으로 저장한다.

```
[1] fetch_fossils.py
    PBDB에서 KR(+ JP, CN 참고) 화석 기록 수집 → raw/pbdb_*.json

[2] merge_manual_sites.py
    수작업 정리한 국내 화석지 CSV 병합 → 중복 제거, 시대 태깅

[3] reconstruct_coords.py
    GPlates로 각 화석지 및 한반도 해안선의 시대별 과거 좌표 계산
    (PBDB 고좌표가 있으면 우선 사용, 없으면 GPlates)

[4] build_paleomaps.py
    PALEOMAP 래스터를 시대별로 웹용 이미지/타일로 변환

[5] build_bathymetry.py
    GEBCO 그리드에서 한반도 주변 영역 추출 → 저해상도 수심 그리드 JSON

[6] build_tree.py
    필요 분류군 학명 목록 → Open Tree TNRS로 ott_id 매칭
    → induced subtree 추출 → 분기 시점 병합 → tree.json

[7] link_species.py
    화석 생물 ↔ 계통수 노드, 한국 현생종 ↔ 계통수 노드 매핑
```

### 5.1 계통수 크기 제한
- Open Tree 전체 사용 금지 (수백만 노드)
- 한국 관련 분류군 + 경로상 필요한 상위 노드만 포함
- 목표: **노드 수천 개 이내**

## 7. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트엔드 | React (Vite 또는 Next.js 정적 export) | 컴포넌트 단위 뷰 연동 |
| 지도 | MapLibre GL JS | 무료, 커스텀 래스터 레이어 용이 |
| 계통수 | D3.js (tree / cluster layout) | 시간축 커스텀 레이아웃 |
| 해수면 렌더링 | Canvas 또는 MapLibre 커스텀 레이어 | 그리드 값 기반 실시간 칠하기 |
| 상태 관리 | Zustand (또는 React Context) | 선택된 시대·생물 전역 공유 |
| 전처리 | Python (requests, pandas, numpy, 필요 시 pygplates / xarray) | |
| 배포 | Vercel 또는 GitHub Pages | 정적 사이트 |

### 7.1 전역 상태
```ts
type AppState = {
  selectedEraId: string;
  selectedFossilId: string | null;
  selectedTreeNodeId: string | null;
  highlightedPath: string[];      // 계통수 하이라이트 경로
  seaLevel: number;               // 빙하기 전용, 0 ~ -130
  mapMode: "paleo" | "modern" | "overlay";
  markerFilter: { groups: string[]; showReference: boolean };
};
```

## 9. 개발 단계

### Phase 0 — 데이터 검증 (1주) ★ 최우선

- **판단 기준**: 백악기 마커 10개 이상 확보 가능하면 진행

### Phase 1 — 백악기 관통 (2~3주)

- **완료 기준**: 고성 발자국 클릭 → 카드 → 계통수 → 까치까지 한 흐름 동작

## 10. 리스크와 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| PBDB의 국내 화석 데이터 빈약 | 마커 부족 | 국가유산청·국내 논문 기반 수작업 보강 |
| 발자국 화석은 종 특정 불가 | 계통수 연결 모호 | 그룹 단위(수각류 등)로 연결, 배지 표시 |
| 해양 파충류 국내 화석 거의 없음 | 콘텐츠 공백 | 동아시아 참고 레이어로 처리 |
| 고지리 지도 정밀도 한계 | 오해 소지 | 대륙 규모 배치 위주, "모델 기반 추정" 명시 |
| 계통수 과대 | 브라우저 성능 저하 | 서브트리 추출, 노드 수천 개 이내 |
| 분기 시점 데이터 확보 난이도 | 시간축 부정확 | 주요 분기만 수작업, 나머지 상대 배치 |
| 외부 데이터 라이선스 | 배포 제약 | Phase 0에서 확인, 출처 표기 |

## 11. 정확성 가이드라인

- 계통수는 현재 가장 지지받는 가설이며 확정된 사실이 아님을 안내
- 특정 화석 종을 현생 종의 **직계 조상**으로 그리지 않는다 → 공통 조상·친척 관계로 표현
- 논쟁 중인 분기, 불확실한 고지리(예: 대한해협 폐쇄 여부)는 점선/해칭/배지로 표시
- "공룡이 아닌" 그룹(익룡, 수장룡, 어룡, 모사사우루스)은 명확히 구분
- 모든 수치(연대, 해수면, 좌표)에 출처 연결
